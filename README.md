# The Sacred Garden (Zohan & Rose Wedding Invitation)

A luxury interactive wedding invitation web experience featuring an animated wax seal envelope, background music, video canvas elements, and responsive event details.

## Features
- **Wax Seal Opening Sequence**: Interactive sealed envelope with fluid video reveal and transition.
- **Ambient Audio**: Built-in background soundtrack with floating play/pause control.
- **Video Elements**: Dynamic background video elements.
- **Typography & Details**: Curated luxury fonts, schedule timeline, Google Maps location, and Add to Calendar links.
- **Fully Self-Contained**: All fonts, styles, scripts, videos, audio, and graphics are bundled locally.

## Local Development
Run the local server:
```bash
python server.py
```
Then open: [http://localhost:5500](http://localhost:5500)
